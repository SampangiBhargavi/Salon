# ✨ LuxeGlow Salon & Spa

LuxeGlow Salon & Spa is a **responsive frontend website** designed for a modern beauty salon and spa.

The website provides customers with an attractive and easy-to-use interface to explore salon services, view beauty treatments, check offers, learn about the salon, and contact the business.

---

## 📌 Project Overview

LuxeGlow Salon & Spa is designed to provide a digital presence for a professional salon.

Customers can explore different beauty and wellness services through a clean and responsive website.

The project focuses on:

* Modern salon design
* Responsive layout
* Easy navigation
* Service presentation
* Beauty and wellness information
* Offers and promotions
* Customer contact
